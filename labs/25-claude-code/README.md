Claude Code is Anthropic's coding agent for the terminal, and it can run on the Claude models in Microsoft Foundry.
Send its requests through your gateway, and Claude Code gets the same controls as your apps: a key that you can
suspend, a token limit and a budget for each caller, and usage in Monitoring. Developers don't need an Anthropic
account, and Claude Code never sees a Foundry credential, because the gateway calls Foundry with its managed
identity. In this lab you publish Claude Opus 5.5, Sonnet 5.5, and Haiku 5.5 for Claude Code, connect it with a few
environment variables, and give it Microsoft Learn tools from an MCP server on the same gateway. Then you run into
the token limit and the budget, and see how Claude Code reports them.

## How it works

Claude Code speaks Anthropic's Messages API, and the gateway serves that API for the Claude models in Foundry on its
Anthropic route, `/default/models/anthropic`. Point Claude Code at that route, and every model call goes through the
gateway. Claude Code still runs its agent loop on your machine: it reads files, edits them, and runs commands, and
only the model calls leave for the gateway. Five environment variables do it:

| Variable | Value | Why |
|---|---|---|
| `ANTHROPIC_BASE_URL` | `https://<gateway-host>/default/models/anthropic` | The gateway's Anthropic route. Claude Code adds `/v1/messages` itself, so leave out `/v1`. |
| `ANTHROPIC_AUTH_TOKEN` | The `claude-code` runtime key | Claude Code sends it as `Authorization: Bearer`, which the gateway accepts. Don't use `ANTHROPIC_API_KEY`: Claude Code sends that one in an `x-api-key` header, and the gateway rejects it with `401`. |
| `ANTHROPIC_DEFAULT_OPUS_MODEL` | `<foundry-account-name>/claude-opus-5-5` | The alias behind the `opus` tier, Claude Code's default model in this setup. |
| `ANTHROPIC_DEFAULT_SONNET_MODEL` | `<foundry-account-name>/claude-sonnet-5-5` | The alias behind the `sonnet` tier. |
| `ANTHROPIC_DEFAULT_HAIKU_MODEL` | `<foundry-account-name>/claude-haiku-5-5` | The alias behind the `haiku` tier, which Claude Code also uses for small background tasks. |

Claude Code picks a model by tier, so `--model sonnet` or `/model sonnet` switches it to the Sonnet alias. A model that
you saved with `/model`, or set in `ANTHROPIC_MODEL`, replaces the default, so the commands that need Opus pass
`--model opus`. The gateway gives each alias its own policies, and **Caller identity** gives each key its own counters:

| Alias | Token limit for each caller | Cost limit for each caller |
|---|---|---|
| `<foundry-account-name>/claude-opus-5-5` | 100,000 tokens per minute | $5 per day |
| `<foundry-account-name>/claude-sonnet-5-5` | 100,000 tokens per minute | None |
| `<foundry-account-name>/claude-haiku-5-5` | 100,000 tokens per minute | None |

Opus is the default and the most expensive model, so it gets the budget. When a developer spends it, they can carry
on with Sonnet until the budget renews. Two things to know about the numbers:

- **Cached tokens barely count toward the token limit.** Claude Code sends its system prompt and tool definitions
  with every request, about 13,500 tokens, and caches them. In testing, cache reads barely counted toward the
  gateway's token limit, so even a 1,000 tokens-per-minute limit let short questions through. Output tokens are what
  fill it, which is why [Hit the limits](#hit-the-limits) asks for long stories.
- **Claude Code's cost is an estimate.** The `total_cost_usd` that Claude Code reports is its own estimate. The
  gateway's cost limit uses the gateway's meter, so the two don't match exactly.

## Publish your Claude models for Claude Code

Import the three Claude deployments into the gateway, publish an alias for each one with a token limit of 100,000
tokens per minute for each caller, add a daily budget of $5 for each caller to the Opus alias, and create the runtime
key `claude-code`. Pick a track.

<details open><summary><b>🖥️ Portal</b></summary> <!-- gh -->

### Import the Claude deployments

1. Open the [AI Gateway portal](https://ai.gateway.azure.com) and select your gateway in the top bar.
2. Select **Models** › **Add** › **Models from Microsoft Foundry**.
3. Select the subscription and resource group of your Foundry account, then select the `claude-opus-5-5`,
   `claude-sonnet-5-5`, and `claude-haiku-5-5` deployments. Keep **Managed identity** as the
   **Authentication method**.
4. Under **Aliases**, keep **Create an alias for each model** selected, then select **Add models**.

The import names each alias after the Foundry account and the deployment, for example
`<foundry-account-name>/claude-opus-5-5`. Claude Code sends these names in the request's `model` field.

### Add the token limit

1. Select **Policies** › **Add policy**. On the **Type** step, under **Cost & Rate Limits**, select
   **Token rate limit**, then **Next**.
2. On the **Scope** step, select **Individual assets**, select the three Claude aliases, then **Next**.
3. On the **Details** step, set **Time period** to **Per minute**, **Allowed tokens** to `100000`, and
   **Counter dimensions** to **Caller identity**. Select **Create**.

### Add the daily budget to Opus

1. Select **Policies** › **Add policy**. On the **Type** step, under **Cost & Rate Limits**, select **Cost limit**,
   then **Next**.
2. On the **Scope** step, select **Individual assets**, select the `<foundry-account-name>/claude-opus-5-5` alias,
   then **Next**.
3. On the **Details** step, under **Parameters**, set **Budget amount** to `5`, **Renewal period** to **Daily**, and
   **Counter dimensions** to **Caller identity**. Select **Next**.
4. Skip the **Overrides** step, and select **Create**.

[Set a cost budget with cost limits](../07-cost-budgets/README.md) explains the budget's fields and overrides.

### Create the key for Claude Code

1. Select **Access** › **API keys** › **Create API key**.
2. In **Key name**, enter `claude-code` and select **Create**.
3. Copy the value from **API key created successfully**, for example with **Copy & done**, and paste it into your
   shell without echoing it:

### Publish an alias for each model

Name each alias like the portal's import does, `<foundry-account-name>/<deployment>`, with `--routing-name`. Resource
names can't contain `/`, so `-n` uses `-` instead. Each alias gets a token limit of 100,000 tokens per minute for each
caller.

<details open><summary>Bash</summary> <!-- gh -->

```bash title="Bash"
# Publish (or update) an alias for each Claude model, with 100,000 tokens per minute for each caller
for m in claude-opus-5-5 claude-sonnet-5-5 claude-haiku-5-5; do
  az aigateway model-alias set -g "$RG" --gateway-name "$GATEWAY" -n "$FOUNDRY_ACCOUNT-$m" \
    --routing-name "$FOUNDRY_ACCOUNT/$m" \
    --backend-model resource-id="$GATEWAY_ID/workspaces/default/modelProviders/$PROVIDER/models/$m" \
    --policies '[{"type": "tokenLimit", "count": 100000, "period": "minute", "counterKey": ["identity"]}]' \
    --only-show-errors -o none &&
    echo "🔖 Alias $FOUNDRY_ACCOUNT/$m: 100,000 tokens per minute for each caller"
done
```
</details> <!-- gh -->

<details><summary>PowerShell</summary> <!-- gh -->

```powershell title="PowerShell"
# Write the token limit to a file: 100,000 tokens per minute for each caller
ConvertTo-Json -Depth 5 -Compress -InputObject @(
  @{ type = 'tokenLimit'; count = 100000; period = 'minute'; counterKey = @('identity') }
) | Set-Content -Path policies.json

# Publish (or update) an alias for each Claude model with that token limit, then remove the file

// Code: grants the gateway's managed identity the Foundry User role on the account, creates a Foundry provider named
// after the account unless the gateway already has one, registers each deployment as an Anthropic Messages model
// under it, publishes the alias "<account>/<deployment>" for each one with a token limit per caller, adds a cost limit
// per caller to one alias, and creates a runtime API key for Claude Code. The aliases have the same names as the ones
// that the portal's import creates, so the Claude Code settings work with either track. Key values are never outputs.
targetScope = 'resourceGroup'

@description('Name of the existing AI Gateway (Microsoft.ApiManagement/aigateways) in this resource group.')
param gatewayName string

@description('Resource ID of the Foundry account that has the Claude deployments. It can be in another resource group or subscription.')
param foundryAccountId string

@description('Claude deployments to publish, each with the tokens per minute that each caller can use through its alias.')
param claudeModels array = [
  { name: 'claude-opus-5-5', tokensPerMinute: 100000 }
  { name: 'claude-sonnet-5-5', tokensPerMinute: 100000 }
  { name: 'claude-haiku-5-5', tokensPerMinute: 100000 }
]

@description('Deployment whose alias also gets a cost limit. Empty adds no cost limit.')
param budgetModel string = 'claude-opus-5-5'

@description('Budget for each caller, in US dollars. A string, so that it can hold decimals such as 0.05.')
param budgetAmount string = '5'

@description('Renewal period of the budget. Budgets renew in fixed calendar windows.')
@allowed([ 'hour', 'day', 'week', 'month', 'year' ])
param budgetPeriod string = 'day'

@description('ID of the cost limit. Keep it to keep the spend counted so far; change it to start a new count.')
param budgetId string = 'claude-code-budget'

@description('Grant the gateway\'s managed identity the Foundry User role on the account. Set it to false when the role is already assigned, for example by the portal\'s import.')
param grantFoundryUser bool = true

@description('Create the Foundry provider named after the account. Set it to false when the gateway already has it, for example from the portal\'s import, so that the template keeps its settings, such as its authentication.')
param createProvider bool = true

@description('Name of the runtime API key to create for Claude Code.')
param apiKeyName string = 'claude-code'

var foundryAccountName = last(split(foundryAccountId, '/'))
var foundrySubscriptionId = split(foundryAccountId, '/')[2]
var foundryResourceGroup = split(foundryAccountId, '/')[4]

#disable-next-line BCP081
resource gateway 'Microsoft.ApiManagement/aigateways@2025-09-01-preview' existing = {
  name: gatewayName
}

#disable-next-line BCP081
resource workspace 'Microsoft.ApiManagement/aigateways/workspaces@2025-09-01-preview' existing = {
  parent: gateway
  name: 'default'
}

resource foundryAccount 'Microsoft.CognitiveServices/accounts@2025-04-01-preview' existing = {
  scope: resourceGroup(foundrySubscriptionId, foundryResourceGroup)
  name: foundryAccountName
}

// Read each deployment, so that the models record the model and version that Foundry serves.
resource deployments 'Microsoft.CognitiveServices/accounts/deployments@2025-04-01-preview' existing = [for m in claudeModels: {
  parent: foundryAccount
  name: m.name
}]

var foundryEndpoint = foundryAccount.properties.endpoint
var roleAssignments = '${foundryAccountId}/providers/Microsoft.Authorization/roleAssignments'

module foundryUserRole '../../02-first-model-call/infra/foundry-user-role.bicep' = if (grantFoundryUser) {
  name: take('foundry-user-${uniqueString(gateway.id, foundryAccountId)}', 64)
  scope: resourceGroup(foundrySubscriptionId, foundryResourceGroup)
  params: {
    foundryAccountName: foundryAccountName
    gatewayPrincipalId: gateway.identity.principalId
    gatewayResourceId: gateway.id
  }
}

#disable-next-line BCP081
resource provider 'Microsoft.ApiManagement/aigateways/workspaces/modelProviders@2025-09-01-preview' = if (createProvider) {
  parent: workspace
  name: foundryAccountName
  dependsOn: [
    foundryUserRole
  ]
  properties: {
    kind: 'Foundry'
    displayName: foundryAccountName
    foundry: {
      endpoint: endsWith(foundryEndpoint, '/') ? foundryEndpoint : '${foundryEndpoint}/'
      resourceIds: [
        foundryAccountId
      ]
      authentication: {
        kind: 'ManagedIdentity'
        managedIdentity: {
          resource: 'https://cognitiveservices.azure.com/'
        }
      }
    }
  }
}

// The models go under the provider, whether the template created it or the gateway already had it.
#disable-next-line BCP081
resource accountProvider 'Microsoft.ApiManagement/aigateways/workspaces/modelProviders@2025-09-01-preview' existing = {
  parent: workspace
  name: foundryAccountName
}

// Claude deployments speak the Anthropic Messages API, so the gateway serves them on /default/models/anthropic.
#disable-next-line BCP081
resource models 'Microsoft.ApiManagement/aigateways/workspaces/modelProviders/models@2025-09-01-preview' = [for (m, i) in claudeModels: {
  parent: accountProvider
  name: m.name
  dependsOn: [
    foundryUserRole
    provider
  ]
  properties: {
    displayName: m.name
    supportedEndpoints: [
      '/anthropic/v1/messages'
    ]
    deployment: {
      resourceId: deployments[i].id
      modelName: deployments[i].properties.model.name
      modelVersion: deployments[i].properties.model.version
    }
  }
}]

var budgetPolicy = {
  type: 'costLimit'
  id: budgetId
  amount: json(budgetAmount)
  period: budgetPeriod
  counterKey: [ 'identity' ]
}

// Each caller identity, a key or a Microsoft Entra identity, gets its own counters.
#disable-next-line BCP081
resource aliases 'Microsoft.ApiManagement/aigateways/workspaces/aliases@2025-09-01-preview' = [for (m, i) in claudeModels: {
  parent: workspace
  name: '${foundryAccountName}-${m.name}'
  properties: {
    aliasName: '${foundryAccountName}/${m.name}'
    backendModels: [
      { resourceId: models[i].id }
    ]
    policies: concat([
      {
        type: 'tokenLimit'
        count: m.tokensPerMinute
        period: 'minute'
        counterKey: [ 'identity' ]
      }
    ], m.name == budgetModel ? [ budgetPolicy ] : [])
  }
}]

#disable-next-line BCP081
resource apiKey 'Microsoft.ApiManagement/aigateways/apiKeys@2025-09-01-preview' = {
  parent: gateway
  name: apiKeyName
  properties: {
    displayName: apiKeyName
  }
}

output gatewayUrl string = 'https://${gateway.properties.frontend.defaultHostname}'
output anthropicBaseUrl string = 'https://${gateway.properties.frontend.defaultHostname}/default/models/anthropic'
output providerName string = accountProvider.name
output aliasNames array = [for (m, i) in claudeModels: '${foundryAccountName}/${m.name}']
output apiKeyName string = apiKey.name
output roleAssignmentId string = grantFoundryUser ? '${roleAssignments}/${foundryUserRole!.outputs.roleAssignmentName}' : ''
```

</details>

## Publish Microsoft Learn tools for Claude Code

Claude Code calls tools as well as models. Publish an MCP server through the same gateway, and its tool calls get the
same controls as its model calls: one key that you can suspend, one endpoint per tool server, and one place to decide
which tools agents see. Here, the gateway publishes the public Microsoft Learn MCP server as `learn`, so Claude Code
can look up current Microsoft documentation while it codes.

Claude Code then has two connections to the gateway:

| | Models | MCP server |
|---|---|---|
| URL | `https://<gateway-host>/default/models/anthropic` | `https://<gateway-host>/default/toolservers/learn/mcp` |
| How the key is sent | `Authorization: Bearer <key>`, from `ANTHROPIC_AUTH_TOKEN` | The same `Authorization: Bearer <key>` header, which you set yourself |
| Key | `claude-code` | The same `claude-code` key. It needs no extra setup. |

> [!TIP]
> If your gateway already has `learn`, for example from
> [Federate MCP tools behind one endpoint](../04-federate-mcp-tools/README.md), skip to
> [Test the MCP endpoint](#test-the-mcp-endpoint).

Create the `learn` server with one backend, `https://learn.microsoft.com/api/mcp`, under the namespace `learn`. The
Learn server is public, so the backend needs no credentials. Pick a track.

## Go further

- **Sign in with Microsoft Entra ID instead of a key.** If the gateway accepts Entra tokens and you have the
  **AI Gateway Models User** role, as in [Authorize callers with Microsoft Entra ID](../11-entra-rbac/README.md), let
  Claude Code fetch a token itself. Add this setting to `~/.claude/settings.json`:

  ```json title="~/.claude/settings.json"
  {
    "apiKeyHelper": "az account get-access-token --scope https://ai.gateway.azure.com/Data.All --query accessToken -o tsv"
  }
  ```

  Then run `unset ANTHROPIC_AUTH_TOKEN` (Bash) or `Remove-Item Env:ANTHROPIC_AUTH_TOKEN` (PowerShell), and keep it
  out of the `env` block of your settings. If it's still set, Claude Code keeps sending the key as the bearer token
  instead of the helper's token, and the requests still succeed with the key. Claude Code runs the helper again every five minutes by default, so expired tokens
  don't stop long sessions. See [Settings](https://code.claude.com/docs/en/settings).
- **Keep the settings in a file.** Put the `ANTHROPIC_*` variables in the `env` block of `~/.claude/settings.json`,
  so every session uses the gateway without exports. Keep the key in your user settings, not in a project's
  `.claude/settings.json`, which gets committed with the repository.
- **Use Claude Code in VS Code.** The Claude Code extension reads the same variables. Set them in the
  `claudeCode.environmentVariables` setting. See [Use Claude Code in VS Code](https://code.claude.com/docs/en/vs-code).
- **Turn off nonessential traffic.** `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1` turns off Claude Code's telemetry,
  error reports, and automatic updates. See [Environment variables](https://code.claude.com/docs/en/env-vars).
- **Give each developer their own key.** Keys are cheap, and **Caller identity** gives each key its own token limit
  and budget. Rotate or revoke them with [Manage runtime API keys](../10-api-keys/README.md).
- **Cap one run.** `claude -p --max-budget-usd 1` stops a one-shot run when Claude Code's own estimate reaches $1. The
  gateway's budget stays the limit that Claude Code can't change.
- **Choose which tools Claude Code can call.** On the gateway, publish only some Learn tools or cap tool calls per
  caller, as in [Control which tools agents can call](../05-mcp-tool-controls/README.md). In Claude Code, use
  `--allowedTools`, `--disallowedTools`, and `--permission-mode`.
- **Route across models.** Point an alias at several backend models, as in
  [Route by priority and weight](../22-model-routing/README.md), and Claude Code keeps sending the same name.
