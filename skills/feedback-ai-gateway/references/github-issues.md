# No longer used

This file is kept for reference. The feedback skill no longer supports GitHub
issue publication.

The anonymized summary file is returned to the user. All decisions about where
and how to share it are the user's responsibility. The skill does not suggest,
facilitate, or perform any uploads to GitHub, email, or other services.

If the user chooses to report feedback manually, they may do so at
`https://github.com/Azure/aigateway/issues/new` using their own anonymized
summary and following the repository's issue template.
