# /aigateway:feedback

Route `$ARGUMENTS` to `skills/feedback-ai-gateway/SKILL.md` for the support utility.
That skill and its local helper own collection consent, anonymization and sharing
approval; this shortcut adds no separate workflow or automatic collection.
